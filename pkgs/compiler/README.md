# mekuru-compiler

[日本語](README.jp.md)

The Rust compiler for Mekuru Movie Maker. Reads XML generated by [@mekuru/core](../core/README.md), resolves timing and layout, renders frames, mixes audio, and encodes video through ffmpeg.

Building requires Rust 1.89 or later and a C linker. Rendering requires ffmpeg with libx264, ffprobe, and suitable fonts.

From the repository root:

```sh
cargo build -p mekuru-compiler --release --locked
./target/release/mekuru-compiler path/to/main.xml -o video.mp4
```

- `--emit-preview` outputs JSON for the browser viewer.
- `--scale`, `--fps`, `--from`, and `--to` control output size, frame rate, and time range.
- Published projects normally launch this compiler through [@mekuru/cli](../cli/README.md).

See [XML syntax](../../docs/reference/Syntax.md) and [development](../../docs/dev/Developer.md).
