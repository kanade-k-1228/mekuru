# @mekuru/protocol

コンパイラ出力とサーバー状態を共有するTypeScript型です。実行時依存はありません。viewer がこの通信契約を参照し、ネイティブサーバーが Rust で実装します。

要素は元の `ViewOp` ごとの SHA-256 描画 ID を順に参照し、プレビューキーは描画内容やコンパイラの連番と独立に要素を識別します。文字は内容・配置・スタイルを持つ `TextOp` で、viewer が HTML/CSS で描画します。`fontSrc` と `fontRevision` はプロジェクト内のフォントを識別します。画像・動画・音声もリビジョンを持ちます。動画書き出しには Rust の組版・パス描画を使います。

`/api/ws` の WebSocket で、1メッセージにつき1件の `PreviewEvent` JSON テキストを送ります。`snapshot` は現在のシーンとリソース、`status` はサーバー状態だけ、`patch` は基準・次のバージョン、キー付きの差分、順序、リソースの変更を運びます。基準バージョンが合わない場合、viewer は `PreviewCommand` の `{"type":"resync"}` を送り、同じ接続で snapshot を再取得します。切断・再同期のタイムアウト時は再接続します。ビューアはコンパイラへ埋め込んで同時に配布します。
