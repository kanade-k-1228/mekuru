# 設計

[English](Concept.jp.md)

Mekuru は、セリフに合わせて画像や動画を並べる解説動画向けのツールです。台本を TSX の部品で組み立て、コンパイラが時間と配置を決めます。

## 時間と空間

入れ物は一つの軸に子を並べ、ほかの軸では重ねます。並べる軸の長さは合計、重ねる軸は最大値で決まります。

- `<seq>`: 時間
- `<row>`: 横
- `<column>`: 縦
- `<stack>`: なし。すべて重ねる

セリフや素材の長さが変わると、場面の長さも変わります。文字・画像など長さを持たない要素は親の終わりまで表示します。`<dur>` は長さを指定し、`<repeat>` は親の終わりまで繰り返します。どちらも空間の配置には影響しません。

時刻は整数フレームで扱い、素材の速度変更で生じた端数は切り上げます。時間の参照は依存グラフとして解き、循環参照はエラーにします。規則と計算式は[組み込み要素](Syntax.jp.md)にまとめています。

## 処理の流れ

1. Bun が TSX を実行し、読み上げ音声と厳格な XML を生成する。
2. コンパイラが文書全体を配置し、素材の長さを調べる。
3. 各要素の開始・終了時刻、表示区間、素材の再生位置を決める。
4. フレームを描画し、音声をミックスして ffmpeg で動画にまとめる。

静的な描画と音声処理はキャッシュします。速度変更した音声は ffmpeg の `atempo` で音程を保ちます。

プレビューも同じ時間・配置・文字パスを使います。コンパイラは表示用の JSON を返し、ブラウザが描画します。プレビューでは PCM の生成と動画のエンコードを行いません。
